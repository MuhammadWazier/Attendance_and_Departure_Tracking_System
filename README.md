# نظام متابعة الحضور والانصراف

## التشغيل محلياً

1. ثبّت Node.js 20 أو أحدث.
2. افتح الطرفية في مجلد المشروع وشغّل `npm install`.
3. شغّل `npm run dev` وافتح العنوان المحلي الذي يظهر في الطرفية.

لإنشاء نسخة الإنتاج، شغّل `npm run build`. ستجد الملفات الجاهزة للنشر في مجلد `dist`.

## النشر عبر GitHub Pages

1. ارفع المشروع إلى المستودع على الفرع `main` أو `master`.
2. من **Settings → Pages** اختر **GitHub Actions** كمصدر للنشر.
3. سيبني سير العمل `.github/workflows/deploy-pages.yml` المشروع وينشر مجلد `dist` مع كل تحديث إلى هذين الفرعين. يمكن أيضاً تشغيله يدوياً من تبويب **Actions**.

تُستخدم مسارات نسبية للملفات الثابتة، لذلك يعمل الموقع على النطاق الرئيسي أو ضمن مسار مستودع. يحتفظ التطبيق بالبيانات في متصفح كل مستخدم؛ البيانات التجريبية أمثلة محلية ولا تتم مشاركتها بين الزوار.

يُحمّل النظام بياناته محلياً في المتصفح. مكتبات الرسوم البيانية وقراءة ملفات Excel والأيقونات تُثبّت مع المشروع، أما خط Cairo فيُحمّل من Google Fonts ويُستخدم في جميع الشاشات والجداول والرسوم البيانية.

## إدارة الحضور والإجازات

- أدخل المديرية والقسم كلّاً على حدة من شاشة **حالة الموظفين الوظيفية** عبر **تعديل بيانات الموظف**؛ يمكن أيضاً تعبئة العمودين عند استيراد ملف Excel، ويظهران في السجلات والتقارير.
- تعرض قائمة **جميع الموظفين وسجلاتهم** الموظفين المسجلين بالحضور أو الحالة الوظيفية أو الإجازات، ويمكن فتح سجل حضور الموظف بالضغط على اسمه؛ لا يتطلب نموذج الاستيراد أو جداول العرض عموداً مستقلاً لليوم إذ يُشتق من التاريخ.
- يتضمن نموذج Excel عمودَي **المديرية** و**القسم** بشكل منفصل. القسم اختياري في الملف وفي الإدخال اليدوي، ويمكن استكماله لاحقاً.
- عيّن أوقات الدوام وأيام العمل من الإعدادات؛ تُعرض أيام الراحة الأسبوعية كراحة عند غياب بصمات الدخول والخروج، وإذا وُجدت البصمتان يُسجل اليوم كدوام في العطلة الأسبوعية ويُحتسب كامل الوقت بينهما إضافياً دون مخالفات تأخير أو خروج مبكر. تُعرض بطاقات لوحة القيادة كإجماليات للسجلات المحفوظة، لا كإحصاء ليوم واحد.
- سجّل رقم الوثيقة عند إضافة إجازة أو مغادرة ليظهر في سجل الإجازات.
- اختر الموظف بالاسم والرقم لتجنب التباس الأسماء، وحدد **إجازة ساعية** لتحديد اليوم ووقت البداية والنهاية. يمنع النظام تداخل الإجازات المعتمدة للموظف.
- يعرض النظام دقائق العمل الإضافي قبل بداية الدوام وبعد نهايته، ووقت الدوام في العطلة الأسبوعية في التقارير وملفات Excel.
- بطاقات لوحة القيادة ومخططاتها تفتح التقارير مع تطبيق فلتر الحالة أو المديرية الموافق.
- يمكن طي القائمة الجانبية أو توسيعها بالنقر على الشعار أعلى القائمة. تظهر شارات الحالة بشكل موحّد وتلتف تسمياتها الطويلة داخل الخلية، مع تمرير أفقي داخل الجدول عند ضيق الشاشة.
